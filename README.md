# 📊 ConsumerFlow | Enterprise FMCG Supply Chain Intelligence

### **"Turning Inventory Data into Strategic Decisions"**

ConsumerFlow is a professional Business Intelligence (BI) dashboard designed for the FMCG sector—specifically modeled after the distribution and sales logic of Indian MNCs like **Marico**. It provides real-time visibility into warehouse health, regional performance, and inventory risks.

---

## 🚀 Key Business Features

* **🇮🇳 Indian Market Localization:** Custom formatting for currency in **Lakhs (L)** and **Crores (Cr)**, aligning with Indian corporate reporting standards.
* **⚠️ Predictive Risk Alerts:** Calculates **Days of Inventory (DOI)** to automatically highlight stock-out risks before they happen.
* **🌍 Regional Intelligence:** Segments performance across North, South, East, and West regions to identify local growth opportunities.
* **💡 Automated Recommendations:** A built-in strategy engine that suggests trade promotions and inventory rebalancing based on current sales velocity.

## 🛠️ Technical Stack

* **Frontend:** [Streamlit](https://streamlit.io/) (Python-based Web Framework)
* **Data Processing:** [Pandas](https://pandas.pydata.org/) & [NumPy](https://numpy.org/)
* **UI/UX:** Custom CSS for enterprise-grade dark-theme styling.
* **Deployment:** Streamlit Community Cloud.

## 📁 Project Structure

* `app.py`: The core application logic and UI.
* `marico_inventory.csv`: The backend dataset containing product levels and sales figures.
* `requirements.txt`: Configuration file for cloud deployment.
* `README.md`: Project documentation.
